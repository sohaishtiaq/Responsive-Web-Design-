Introduction

JavaScript is a programming language used to make web pages interactive.

It works alongside HTML and CSS to create dynamic websites.

JavaScript can run directly in a web browser.

console.log("Hello, World!");
  • JavaScript is widely used in web development.
  • It supports both frontend and backend development.
JavaScript Basics

JavaScript statements are instructions that a computer executes.

Statements are often separated by semicolons.

Comments help explain your code to other developers.

let message = "Welcome"; console.log(message);
  • Use meaningful variable names.
  • Indent your code for readability.
Variables

Variables store values that can be used throughout a program.

You can declare variables using let, const, or var.

Use let when a variable's value needs to change.

let age = 20; const country = "Pakistan";
  • Use const for bindings that should not be reassigned.
  • Use let for values that may change.
Functions

Functions are reusable blocks of code designed to perform a task.

A function can accept parameters and return a value.

You can call a function whenever you need its functionality.

function greet() { console.log("Hello!"); } greet();
  • Functions help reduce repeated code.
  • Parameters allow functions to receive input.
Loops

Loops execute a block of code repeatedly.

A for loop is useful when you know how many times to repeat an action.

A while loop continues while its condition remains true.

for (let i = 0; i < 5; i++) { console.log(i); }
  • Use loops to process collections of data.
  • Make sure loop conditions eventually become false.
Arrays

An array stores multiple values in a single variable.

Array indexes start at zero.

You can add, remove, or access elements using array methods.

const colors = ["red", "green", "blue"]; console.log(colors[0]);
  • Use push() to add an item to the end.
  • Use pop() to remove the last item.
  • Use length to find the number of elements.
